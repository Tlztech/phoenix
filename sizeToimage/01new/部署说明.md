# 尺码表转图片工具 —— 新电脑部署说明

脚本功能：读取 Excel 中的 Description 尺码表，用 Chrome 无头浏览器渲染成图片，
上传到七牛云并把图片地址写回 Excel。

## 一、环境要求

| 项目 | 要求 | 说明 |
|------|------|------|
| 操作系统 | Windows 10/11 | 脚本在 Win10 上开发验证 |
| Python | 3.10 以上（建议 3.12） | 原机器为 3.12.10 |
| Google Chrome | 正式版，任意较新版本 | 脚本用 Chrome 渲染，必须安装 |
| 网络 | 可访问外网 | 首次运行要下载 chromedriver；上传图片走七牛云 |

七牛云的 AccessKey / SecretKey / Bucket 已写在脚本里，不需要额外配置。

## 二、部署步骤

### 1. 安装 Python

到 https://www.python.org/downloads/ 下载 Python 3.12 安装包。
安装时**务必勾选 "Add python.exe to PATH"**，其余默认下一步。

装完打开 cmd 验证：

```
python --version
```

能显示版本号（如 `Python 3.12.10`）即成功。

### 2. 安装 Google Chrome

到 https://www.google.com/chrome/ 下载安装，默认安装即可。
不需要手动下载 chromedriver——脚本首次运行时会通过 webdriver-manager 自动下载匹配版本。

### 3. 拷贝项目文件

在新电脑上建目录（路径可自定，例如 `C:\project\phoenix\sizeToimage\01new`），
把以下文件拷进去：

- `sizetoimageallnew.py` （主脚本，必须）
- `requirements.txt` （依赖清单，必须）
- `run-new.bat` / `run-exist.bat` （快捷启动脚本，可选）

`__pycache__`、`*.jpg` 示例图不用拷。

### 4. 安装 Python 依赖

在项目目录打开 cmd（地址栏输入 cmd 回车），执行：

```
pip install -r requirements.txt
```

依赖清单（原机器已验证的版本）：

| 包 | 用途 | 原机器版本 |
|----|------|-----------|
| pandas | 读写 Excel | 3.0.3 |
| openpyxl | pandas 的 xlsx 引擎 | 3.1.5 |
| pillow | 图片裁剪 | 12.2.0 |
| selenium | 驱动 Chrome 渲染 | 4.46.0 |
| webdriver-manager | 自动下载 chromedriver | 4.1.2 |
| qiniu | 七牛云上传/刷新CDN（需 ≥7.11） | 7.18.0 |

### 5. 验证

把任意一个待处理的 Excel 放到项目目录，执行：

```
python sizetoimageallnew.py 文件名.xlsx 品牌名
```

首次运行会先下载 chromedriver（十几秒），然后开始逐行出图。
生成的图片在 `sizetoimg\品牌名\` 目录下，处理完的 Excel 会另存一份带图片地址的结果文件。

## 三、日常使用

```
python sizetoimageallnew.py 文件名.xlsx 品牌名 [颜色尺码标识] [--skip-existing]
```

- **颜色尺码标识**：`0`（默认）= Code 按 `-` 切分取前段作为货号；非 0 = Code 整体作为货号
- **`--skip-existing`**：七牛上已有同名图片时直接复用，不重新生成

也可以直接改 `run-new.bat` / `run-exist.bat` 里的文件名和品牌名，双击运行：

- `run-new.bat` —— 全部重新生成
- `run-exist.bat` —— 带 `--skip-existing`，复用七牛已有图片

## 四、常见问题

**1. 首次运行卡在下载 chromedriver / 报网络错误**
webdriver-manager 需要访问 googlechromelabs.github.io 下载驱动。
如果网络受限，可在能上网的电脑下载对应 Chrome 版本的 chromedriver.exe
（https://googlechromelabs.github.io/chrome-for-testing/ ），
拷到新电脑的 `C:\Users\<用户名>\.wdm\` 对应目录下（参考原机器同路径结构）。

**2. 报 `文件不存在: xxx.xlsx`**
Excel 要和脚本放在同一目录，或者在命令里写完整路径。

**3. 中文文件名乱码**
用 bat 启动时已有 `chcp 65001` 处理；手动在 cmd 运行出现乱码时，先执行 `chcp 65001` 再跑。

**4. Chrome 升级后报 driver 版本不匹配**
webdriver-manager 一般会自动重新下载匹配版本；不行就删掉 `C:\Users\<用户名>\.wdm\` 目录后重跑。

**5. 上传七牛失败**
检查网络能否访问七牛云；确认 qiniu 包版本 ≥7.11（`pip show qiniu`）。
